# 大学英语四级应试教练

独立的 `cet4-coach` Skill，覆盖四级笔试、四级口语、诊断、专项训练、模考、成绩解释和重考。

核心模块：

- 短篇新闻、长对话、听力篇章。
- 选词填空、长篇匹配、仔细阅读。
- 120 词写作。
- 140—160 字汉译英。
- 四级口语。
- 710 分报道分和 425 分常见门槛解释。

## 安装

```text
~/.codex/skills/cet4-coach/
```

## 示例

```text
四级 425 算不算及格？
我听力 110、阅读 150、写译 120，剩 6 周，先补什么？
给我一篇四级新闻听力的精听流程。
这篇仔细阅读为什么 B 不对，给我定位依据和干扰项类型。
帮我按 125 分钟做一套四级模考与复盘。
```

## 使用边界

- 四级不设官方及格线。
- 不把四级与六级分数直接换算。
- 不虚构官方真题或固定提分。
