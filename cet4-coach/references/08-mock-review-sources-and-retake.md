# 模考、复盘、来源与重考

## 模考

按 125 分钟完整完成：

- 写作。
- 听力。
- 阅读。
- 翻译。

如果使用第三方模拟题，必须标明不是官方真题。分数只作内部训练比较，不直接换算为官方报道分。

## 复盘顺序

1. 时间是否够。
2. 哪些题该拿没拿。
3. 错因是什么。
4. 哪个方法需要重练。
5. 下次复测什么。

不逐题写长篇翻译代替复盘。

## 错因表

| 模块 | 主要错因 | 复测 |
| --- | --- | --- |
| 写作 | 任务不完整、结构、语法、搭配 | 同题重写 |
| 听力 | 音、词、句、注意力、选项 | 精听后重做 |
| 阅读 | 词汇、长句、定位、同义替换、干扰项 | 单篇限时 |
| 翻译 | 主干、时态、单复数、搭配 | 一段重译 |

## 来源

| 等级 | 材料 | 用途 |
| --- | --- | --- |
| A | 官方大纲、公告、样题、FAQ | 规则依据 |
| B | 用户提供且来源清楚的试卷 | 题目分析 |
| C | 机构整理真题、回忆版 | 训练 |
| D | 自编模拟 | 训练 |
| E | 保过、必考、无来源原题 | 不使用 |

## 重考

先判断问题：

- 缺考或 0 分。
- 总分差一点。
- 单模块拖累。
- 时间不足。
- 目标提高。
- 只是需要学校/单位门槛。

计划从最近一次有效成绩出发，不把“多刷几套”当作唯一方案。

## 四级后转六级

四级达标不等于六级自动达标。六级：

- 时间更长。
- 写作词数更高。
- 听力改为长对话、篇章和讲座。
- 翻译段落更长。

这里只做衔接说明；六级训练使用独立的 `cet6-coach`。
