# 示例

## 425 分

用户：

```text
四级考 425 算及格吗？
```

回答：

```text
CET 官方不设及格线，所以不能把 425 称为“官方及格线”。
425 是官方大纲中的基础目标描述点，也是很多学校允许报考六级的常见门槛，
一些用人单位也会把 425、500 等作为自己的招聘或毕业要求。
因此要分三层看：官方不设线、六级报名常看 425、使用方可以另设标准。
```

## 模块分诊断

用户：

```text
总分 470，听力 110，阅读 180，写译 130，还剩 6 周。
```

回答：

```text
先假设这是同一场次有效成绩。当前最明显的短板是听力，阅读相对稳定。
未来 6 周不要平均分配：
1. 听力每天做“原速做题—重听错句—看原文—跟读”的短循环。
2. 阅读保持隔日限时，重点防止为了提听力而丢掉现有优势。
3. 写译每周各两次，先保任务完整和语法。
4. 第 3、5 周做整卷，比较听力和阅读用时变化。

第一次复测看：新闻主旨题是否少错、长对话问答是否跟得上、
以及整卷听力结束后是否还能正常做阅读。
```

## 新闻听力

用户：

```text
四级新闻听力总抓不到重点。
```

回答：

```text
先不追求听懂每个词。新闻题优先抓导语里的主体、事件和结果，
再听时间、地点、数字、原因和回应。
做一段 3 分钟循环：
1. 原速做题；
2. 不看原文重听错句；
3. 看原文标出人名、数字和转折；
4. 跟读导语；
5. 24 小时后只听同一段复述主体和事件。
连续做 5 段，再统计是词不认识、音没听出，还是选项替换没识别。
```

## 写作批改

用户：

```text
帮我改这篇四级作文，目标 120 词。
```

回答：

```text
先不整篇代写，按四级评分动作改：
1. 检查题目要求的每个任务是否回应。
2. 每段是否只有一个中心。
3. 理由后是否有解释或例子。
4. 先修主谓一致、时态、单复数和搭配。
5. 最后才替换低效词汇。
我会保留你的原观点，只重写最关键的一到两段作为示范。
```
