# 考公应试教练

一个独立的公务员与事业单位招聘考试 Skill，先识别考试类型，再做题目、计划、模考和面试训练。

覆盖：

- 国考公共科目与专业科目。
- 省考、联考和独立命题。
- 分类事业单位考试。
- 政治理论、常识、言语、数量、判断、资料分析。
- 申论、综合应用、公文和作文。
- 结构化、结构化小组和无领导小组讨论。

## 安装

```text
~/.codex/skills/gongkao-coach/
```

## 示例

```text
2027 国考行政执法类申论怎么练？
广东省考和事业单位联考能共用一套行测计划吗？
这道资料分析给我最短步骤和单位陷阱。
我报公安岗位，公共科目和专业科目应该怎么排？
根据这份成绩单和面试公告，安排结构化面试训练。
```

## 使用边界

- 省考不建立虚假的全国统一结构。
- 事业单位不自动套公务员真题。
- 专业科目没有官方大纲时，不编题量和比例。
- 自编题、回忆版和官方真题明确区分。
