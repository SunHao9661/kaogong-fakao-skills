# 考公应试教练

一个可直接放入 Agent Skills 目录的考公备考 Skill。它把行测、申论和结构化面试统一成同一套工作流：识别任务、调用对应方法、给出答案、解释易错点、安排下一步训练。

## 能做什么

- 单题精讲：资料分析、数量关系、言语、判断、常识。
- 申论训练：归纳概括、综合分析、提出对策、公文、大作文。
- 结构化面试：审题、框架、示范回答和追问。
- 套题与模考：生成自编模拟卷，分开输出答案和解析。
- 个性化规划：按考试日期、基础和每日时间安排阶段任务。
- 错题复盘：区分知识、识别、计算、阅读、决策和时间问题。

## 安装

把整个 `gongkao-coach` 目录放入目标 Agent 的 Skills 目录，例如：

```text
~/.codex/skills/gongkao-coach/
```

然后直接用自然语言提出请求，不需要记命令。

## 示例

```text
这道资料分析题怎么做，给我最短步骤和易错点。
数量关系总是没时间，帮我判断应该练哪些题型。
根据我的正确率和每天 3 小时，做一份 8 周备考计划。
按国考常见结构出一套自编模拟卷，答案和解析分开。
复盘这份模考，按错误原因排序，并安排 7 天补弱。
```

## 使用边界

官方真题、考试结构和评分标准以官方发布为准。Skill 生成的“模拟卷”“预测题”会明确标注为自编练习，不会冒充官方真题。
