# 示例

## 2027 国考申论分类

用户：

```text
2027 国考申论怎么准备？
```

回答：

```text
先看你的职位属于哪一类，因为 2027 国考申论按三类职位分别命题：
1. 中央机关及其省级直属机构综合管理类；
2. 市地级及以下直属机构综合管理类；
3. 行政执法类。

三类都练材料阅读、概括、分析、对策和写作，但重点不同：
综合管理类更重综合分析和解决问题；市地级更重贯彻执行；
行政执法类更重依法办事和公共服务。
告诉我职位代码或招考简章中的类别，我才能按正确卷种排计划。
```

## 省考不默认国考

用户：

```text
省考行测多少题？
```

回答：

```text
这个问题不能只给一个全国数字。省考题型、题量、模块、申论分卷和考试时间
要按省份和年份查公告。联考也不等于所有地区同卷。
请告诉我省份和考试年份，我先按当地官方结构建立考试地图。
```

## 事业单位与公务员

用户：

```text
事业单位综合应用能力能用公务员申论的方法吗？
```

回答：

```text
材料阅读、任务拆解和规范表达有共通方法，但不能直接等同。
事业单位分类考试的岗位类别不同，综合应用能力任务也不同；
必须看考试大纲和岗位类别。
公务员申论的三类卷也不能自动套到事业单位。
```

## 政治理论题

用户：

```text
为什么这句话的主体是对的、表述也熟悉，却不是答案？
```

回答：

```text
政治理论题不只看“表述熟不熟”。还要核对题干主体、范围、时间、程度和任务。
“正确表述”如果放错主体、扩大了适用范围，或答的是另一个层级，仍然不能选。
我会先标题干限定词，再逐项写保留/排除理由。
```

## 公安岗位计划

用户：

```text
2027 国考公安岗位怎么排？
```

回答：

```text
先按职位公告确认：你除了行测、申论，还要考公安专业科目。
笔试合成按行测 40%、申论 30%、专业 30%，所以专业科目不能最后一周才补。
同时要单独核验年龄、体能、体检、考察等特殊要求。
请给剩余周数和当前三科水平，我再按合成权重排计划。
```
