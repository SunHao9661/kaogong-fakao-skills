# 示例

## 资料分析单题

用户：

```text
某地 2023 年服务业增加值 4800 亿元，比 2022 年增长 20%。2022 年服务业增加值是多少？
```

回答：

**结论：4000 亿元。**

**题型：**已知现期量和增长率，求基期量。

**最短解题链：**

```text
基期 = 现期 ÷ (1 + 增长率)
= 4800 ÷ 1.2
= 4000
```

**易错点：**不要把 4800 直接除以 20%，也不要把增长率减到现期上。

**可复用规律：**`B = A(1+R)`，所以 `A = B/(1+R)`。

## 数量关系筛选

用户：

```text
数量关系只剩 8 分钟，3 道工程题、4 道复杂行程、3 道容斥，怎么选？
```

回答：

先做容斥和可直接赋公倍数的工程题，复杂行程题只在题干关系能一眼写出一条等式时再做。

具体流程：

1. 40 秒扫题，标出“能赋值、能代入、能排除”的题。
2. 先做 2 道最有把握的题。
3. 剩余时间只回看不确定的题，不再开新的大计算。

这不是按某个固定选项蒙题；可选题型取决于你能否稳定完成。

## 申论提纲

用户：

```text
材料讲社区养老，题目要求概括主要问题并提出对策。
```

回答骨架：

**问题得分点示例：**

- 服务供给与老人需求不匹配。
- 专业照护人员不足。
- 信息分散，资源调度效率低。

**对策：**

1. 由街道建立需求清单，按失能程度分类服务。
2. 联合职业院校开展照护培训，形成兼职和志愿服务补充队伍。
3. 建统一信息台账，连接社区、机构和家庭，定期回访服务效果。

每条对策都从材料问题出发，不新增未经材料支持的数据。

## 8 周计划摘要

用户：

```text
每天 3 小时，资料分析速度和正确率都不稳定，8 周后考试。
```

回答：

```text
第 1 周：2 套资料分析基线 + 错因分类。
第 2-3 周：每天 2 篇限时资料 + 20 分钟计算复盘。
第 4 周：资料与判断混合训练，观察切换损耗。
第 5-6 周：每周两次行测混合卷，一次申论整题。
第 7 周：完整模考 + 按错因补弱。
第 8 周：两次完整节奏模拟，稳定答题顺序。

检查点：资料分析正确率达到 85%，单篇平均用时比基线少 2 分钟；
若连续两次没达到，先减少题量，重新训练定位和列式，而不是继续刷整套。
```
