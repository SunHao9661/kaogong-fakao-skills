# 公务员与事业单位面试

## 先确认形式

可能包括：

- 结构化面试。
- 结构化小组。
- 无领导小组讨论。
- 材料题。
- 专业能力测试或技能测试。

形式、题量、时间、是否有题本、是否看题/听题，以面试公告和招录机关要求为准。

## 通用目标

一分钟内说清：

- 问题是什么。
- 你的判断或目标。
- 两到三条具体措施。
- 如何检查结果。

## 结构化

### 综合分析

```text
判断/观点
→ 原因、意义或风险
→ 对策
→ 公共价值或工作落点
```

### 组织管理

```text
目标
→ 对象与需求
→ 方案与分工
→ 风险预案
→ 评估反馈
```

### 应急应变

```text
先控风险/安全
→ 核实
→ 分类处置
→ 回应
→ 复盘机制
```

### 人际沟通

```text
稳定情绪
→ 明确职责
→ 沟通事实
→ 解决工作问题
→ 形成机制
```

### 岗位匹配

```text
选择原因
→ 能力证据
→ 入职后的具体行动
```

## 结构化小组

增加三类能力：

- 答题。
- 点评。
- 回应。

点评先肯定具体有效点，再指出一个可改进点，并给可执行建议。回应不机械反驳。

## 无领导

角色不是“抢领导”，而是推动任务：

- 明确目标。
- 补充信息。
- 归纳分歧。
- 提出可执行标准。
- 帮小组形成结论。

不打断、不垄断、不为了表现而制造冲突。

## 措施

每条至少写清：

1. 谁做。
2. 做什么。
3. 怎么做。
4. 如何判断有效或控制风险。

反例：

```text
加强沟通，提高服务。
```

可用表述：

```text
由业务骨干在工作日晚间集中答复高频问题，用回访记录检查一次解决率。
```

## 训练

- 先写提纲口述。
- 录音检查第一句、结构和重复。
- 完整模拟后由他人追问。
- 每次只改一个最关键问题。

## 质量检查

- 与面试形式匹配。
- 身份和权限正确。
- 措施有动作和结果。
- 不空喊口号。
- 不泄露或编造面试真题。
