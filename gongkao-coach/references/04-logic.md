# 判断推理

## 图形推理

按固定观察顺序排查，避免随机猜：

1. 元素组成是否相同。
2. 位置是否移动、旋转、翻转。
3. 样式是否叠加、去同存异、去异存同。
4. 数量关系：点、线、面、角、笔画、部分数、封闭区域。
5. 属性关系：对称性、曲直性、开闭性、重心、方向。
6. 图形间关系：相交、相切、包含、相邻、遍历。

先找一条在所有图形中都能成立的规律，再用选项验证。规律只在少数图形成立时，通常不是主规律。

## 定义判断

把定义拆成要素：

```text
主体 + 行为/事件 + 条件 + 目的/结果 + 排除情形
```

逐项对照，任何一个必要要素不满足即可排除。注意：

- 定义中的“可以”“必须”“因……而……”都有作用。
- 不属于定义的现象不因为“看起来合理”而成立。
- 选项含多个动作时，检查核心动作是否满足。

## 类比推理

先判断最直接的一阶关系：

- 种属、组成、功能、材料、地点、时间、因果、条件、目的。
- 语义近反、程度、感情色彩、象征。
- 语法结构：主谓、动宾、偏正、并列。

一阶关系相似时，再用二级关系区分。不要用生僻联想替代题干明确关系。

## 翻译推理

常见形式：

```text
如果 A，那么 B：A → B
只有 A，才 B：B → A
除非 A，否则 B：¬A → B
A 且 B：二者都真
A 或 B：至少一真
```

有效推理：

- 肯前推肯后。
- 否后推否前。

常见错误：

- 否前推否后。
- 肯后推肯前。
- 把“或”当成“且”。

必要时把条件符号化，逐项验证，不凭语感。

## 真假推理

1. 找矛盾关系：必有一真一假。
2. 找反对、包含或推出关系。
3. 结合“只有一真/只有一假”的总量限制。
4. 用假设法验证，假设后必须检查所有条件同时成立。

## 加强削弱

先写论证链：

```text
论据 → 隐含假设 → 结论
```

加强：补足隐含假设、解释因果关系、排除他因、增加实例。

削弱：切断因果、提出他因、指出样本偏差、说明结果不可比、反例成立。

题干谈“比例”时，不要只说人数多少；题干谈“平均”时，不要用极端个案替代总体。

## 日常结论与解释

- 只选能由题干必然推出的内容。
- “可能”通常比“必然”更容易成立，但仍需有题干依据。
- 解释现象要同时说明原现象为何发生、表面矛盾为何能共存。

## 训练方法

按题型分开训练，每组只记录三个数：识别用时、规律是否正确、选项排除是否充分。错误率高时先补专项规律，错误率低但慢时再做混合限时。
