# 申论、公文与作文

## 总流程

```text
审题 → 定任务 → 找材料 → 分类加工 → 组织结构 → 书写 → 回查
```

## 审题

至少确认：

- 作答身份。
- 作答对象。
- 任务动词：概括、分析、提出、评价、起草。
- 范围：给定材料哪几则。
- 字数、格式、条数。
- 是否需要结合实际，还是只能依据材料。

任务没看清时，写得再多也会失分。

## 找材料

把材料按“问题、原因、影响、做法、成效、观点、案例”标记。用短词做旁注，不整段抄写。

每一条答案都尽量能回答：

```text
这条信息来自哪里？
它对应题目哪个任务？
它和其他要点是否重复？
```

## 归纳概括

步骤：

1. 给材料要点编号。
2. 合并同义项。
3. 按主体、维度或因果关系归类。
4. 用短句写“总—分”结构。

表达模板：

```text
一是……；二是……；三是……
```

不要只罗列材料中的例子，要提炼例子的共同结论。

## 综合分析

常见结构：

```text
判断/释义 → 分析原因或意义 → 分析问题或影响 → 得出对策/结论
```

如果题目问“谈谈理解”，先解释关键词，再说明其现实含义。不能直接抄材料句子当作分析。

## 提出对策

一条对策尽量写全：

```text
谁 + 做什么 + 怎么做 + 达到什么结果
```

对策来源要与材料问题对应。材料没提的新增做法可以合理推演，但不能写成已经发生的政策。

## 公文写作

先确定：

- 文种。
- 发文机关与收文对象。
- 目的。
- 语气。
- 必要格式。

无明确模板时，采用“标题—称谓—背景/目的—事项—要求—落款”的通用骨架，并说明这是训练用格式。

## 大作文

### 立意

从题干关键词和材料主旨共同确定中心论点。中心论点应满足：

- 回应题目。
- 能覆盖材料主要矛盾。
- 有可展开的三个分论点。

### 结构

推荐：

```text
开头：切入问题 + 亮明中心论点
分论点一：为什么/是什么 + 材料证据 + 分析
分论点二：另一维度 + 材料证据 + 分析
分论点三：行动/保障 + 材料证据 + 分析
结尾：回扣主题 + 提炼价值
```

分论点之间要有真实区分，不把同一句话换三种说法。

### 论据

- 材料内事实优先。
- 外部案例、政策、数据必须准确；不确定就不写。
- 例子后必须有分析，说明它如何支持分论点。
- 不使用空泛排比代替论证。

## 语言

- 用具体动作代替空泛形容词。
- 一句话只表达一个中心意思。
- 关键词复现要有节制，避免口号堆叠。
- 长句分段，保证阅卷时能快速看到得分点。

## 回查

- 是否完全回答了题干。
- 条数和字数是否符合。
- 是否存在同类要点重复。
- 是否超出材料范围或虚构事实。
- 开头、分论点、结尾是否围绕同一中心。
