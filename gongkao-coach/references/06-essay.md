# 申论、综合应用与公文

## 先确认考试和类别

### 国考

2027 国考申论分三类职位分别命制：

- 中央机关及其省级直属机构综合管理类。
- 市（地）级及以下直属机构综合管理类。
- 行政执法类。

三类能力要求和材料落点不同，不能一份模板答所有卷。

### 省考

确认省份、年份、职位层级和申论类别。不同地区可能有不同卷种和能力侧重。

### 事业单位

可能使用综合应用能力、公共基础知识、写作或其他科目，不是公务员申论同义词。按岗位类别和当年大纲。

## 通用流程

```text
读作答要求
→ 确认身份、对象、任务、范围、字数
→ 读材料并标注
→ 合并归类
→ 组织答案
→ 回查任务和字数
```

## 材料标注

- 问题。
- 原因。
- 影响。
- 做法。
- 成效。
- 观点。
- 案例。
- 争议。

每条答案能回答：来自哪段、对应哪个任务、与别条是否重复。

## 归纳概括

```text
一是……
二是……
三是……
```

先提炼共同点，不把例子简单拼接。

## 综合分析

```text
判断/解释
→ 原因、意义或问题
→ 影响或关系
→ 结论/对策
```

题目问“理解”，先解释关键词和关系。

## 提出对策

```text
主体 + 动作 + 方式 + 结果
```

材料问题是依据。可合理推演，但不能写成已发生政策。

## 公文

先确认：

- 文种。
- 发文和收文主体。
- 目的。
- 语气。
- 必要格式。
- 字数。

无明确格式时用训练骨架并标注，不把培训格式冒充机关正式规范。

## 大作文

### 立意

题干关键词和材料主旨共同决定中心论点。

### 结构

```text
开头：问题/关系 + 明确观点
主体：2—3 个有区分度的分论点
结尾：回扣主题 + 行动或价值
```

### 论证

- 材料事实优先。
- 外部例子必须准确。
- 例子后分析。
- 不用排比代替论证。

## 三类国考申论的能力差异

### 中央及省级综合管理

更重综合分析、提出和解决问题、文字表达。练全局关系、本质和论证。

### 市地级及以下综合管理

更重贯彻执行的场景性。练任务理解、对象、组织实施和落地表达。

### 行政执法

更重依法办事和公共服务。练权限、程序、群众需求、处置边界和服务表达。

这些是能力重点，不是固定题型清单；具体题目看当年大纲和试卷。

## 回查

- 每问都答。
- 条数和字数。
- 不重复。
- 材料依据。
- 不虚构政策、数字、人物。
