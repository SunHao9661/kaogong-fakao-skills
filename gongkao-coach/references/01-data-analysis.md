## 读题顺序

1. 先读问题，圈出时间、指标、单位和问法。
2. 再回材料定位该时间、该指标；不要从头通读。
3. 在草稿上写“求什么—给什么—用哪条关系”。
4. 估算前先比较选项差距，决定保留几位有效数字。

常见问法：

- “是几倍”与“多几倍”不同。
- “增长最快/最多”分别对应增长率/增长量。
- “比重上升/下降”看部分增速与整体增速。
- “同比/环比”“累计/当期”“百分数/百分点”必须分清。

## 核心量

设：

- `A`：基期量。
- `B`：现期量。
- `R`：增长率，25% 写作 0.25。
- `X`：增长量。

基本关系：

```text
B = A × (1 + R)
A = B ÷ (1 + R)
X = B - A = A × R = B × R ÷ (1 + R)
R = X ÷ A = (B - A) ÷ A
```

## 常用公式

### 两年平均增长

若从 `A` 增长到 `B`，共 `n` 年：

```text
年均增长率 = (B ÷ A)^(1/n) - 1
```

选择题中通常用选项验证，不必开高次方。

### 比重

```text
比重 = 部分量 ÷ 整体量
```

- 部分增长率 > 整体增长率，通常说明比重上升。
- 部分增长率 < 整体增长率，通常说明比重下降。
- “上升几个百分点”用两个百分数直接相减，不是再除以原比重。

### 平均数

```text
平均数 = 总量 ÷ 个数
```

平均数增长方向由“总量增速”和“个数增速”共同决定。不要只看总量。

### 倍数

```text
B 是 A 的几倍 = B ÷ A
B 比 A 多几倍 = B ÷ A - 1
```

### 混合增长率

整体增速位于两个部分增速之间，并更靠近基期权重较大的部分。比较时优先用基期量，不用现期量替代。

## 速算

### 截位估算

- 选项差距大：保留 2 到 3 位有效数字。
- 选项差距小：保留 3 到 4 位，或改用分数近似。
- 分子分母同时截位可能放大误差；估算后检查结果是否贴近两个选项。
- 除法和乘法优先用“分数化”，不要把每一步都算成小数。

### 415 份数

把常见增长率换成“现期份数/基期份数”：

| 增长率 | 倍数关系 |
| --- | --- |
| +100% | 2/1 |
| +50% | 3/2 |
| +33.3% | 4/3 |
| +25% | 5/4 |
| +20% | 6/5 |
| +16.7% | 7/6 |
| +14.3% | 8/7 |
| +12.5% | 9/8 |
| +11.1% | 10/9 |
| +10% | 11/10 |
| -20% | 4/5 |
| -25% | 3/4 |
| -33.3% | 2/3 |

使用方法：看到精确或近似常见百分数，先把增长关系换成整数份，再求基期、现期或增长量。近似值是否可用，取决于选项差距。

### 交叉相乘

比较两个分数大小时：

```text
a/b 与 c/d
比较 a×d 与 c×b
```

避免先算两个长小数。

## 易错口径

- “增长率下降”不等于“数量下降”；只要增长率仍为正，数量仍在增加。
- “下降 5 个百分点”与“下降 5%”不同。
- 材料中的“万人、亿元、%”可能需要在选项中换算。
- 累计值与单月值不能直接当同期。
- 比重、平均数、倍数的分子分母对象不能互换。
- 题干问“约”，仍要检查量级；问“正确/错误”要先核对所有候选。

## 训练方法

一组训练建议为 1 篇材料 5 题，限时 6 到 8 分钟，记录：

- 定位用时。
- 列式是否正确。
- 计算是否超过 20 秒。
- 错因属于口径、公式、估算还是选项。

连续两组达到目标正确率后，再把 4 篇合并为限时套练。目标时间按考试结构和本人基线调整，不把固定“25 分钟 20 题”当作所有考试的官方标准。
