# 错题复盘、来源与质量检查

## 错因分类

不要只写“粗心”。至少归到以下一项：

| 错因 | 判断信号 | 修复动作 |
| --- | --- | --- |
| 知识缺口 | 不知道概念、公式或方法 | 补一张最小知识卡 |
| 识别失败 | 会方法但没看出题型 | 做同类题干关键词训练 |
| 列式错误 | 对象、时间或单位选错 | 重做“求什么—给什么” |
| 计算错误 | 列式对但结果错 | 限时口算与估算训练 |
| 阅读错误 | 看漏否定、条件、范围 | 逐题圈限制词并复述 |
| 选择错误 | 算对但选了干扰项 | 建立选项排除理由 |
| 时间错误 | 会做但没来得及 | 设定跳题阈值 |
| 策略错误 | 顺序或取舍不合理 | 重排考场流程 |

## 错题卡

```text
题目来源：
题型：
我的答案 / 正确答案：
错误原因：
正确流程（不超过 5 步）：
同类识别词：
24 小时复测结果：
7 天复测结果：
```

## 统计算法

优先看三个指标：

1. **知识错误的重复率**：同一考点是否反复错。
2. **会做但失分率**：知识会、仍然做错，说明流程或状态有问题。
3. **每分耗时**：哪个模块投入多、提升少。

不要根据一次模考直接推翻整个计划。至少观察两次同类训练。

## 来源优先级

### 考试结构

1. 当年招录公告、考试大纲、官方报名指南。
2. 国家公务员局或地方组织/人社部门、人事考试机构。
3. 官方样卷、评分说明。

### 时政与政策

1. 官方文件、会议公报、政府工作报告。
2. 国家统计部门和部委官网。
3. 权威媒体完整转载。

### 法律与常识

1. 现行有效法律和司法解释。
2. 官方机构解读。
3. 权威教材与公开课。

## 引用写法

- 写清来源名称和日期。
- 区分“公告规定”“材料数据”“训练建议”。
- 无法核实的具体数字、政策原文和人名直接省略，不猜。
- 预测内容使用“训练判断”“根据公开考纲整理”，不使用“官方确定”“必考”。

## 发送前检查

- 是否先给答案或完成用户的核心请求。
- 数值是否复算，单位是否一致。
- 材料题是否有题面依据。
- 申论是否区分材料事实与外部延伸。
- 是否把模拟题标注清楚。
- 计划是否有日程、题量、时限和检查点。
- 是否给了一个可以今天执行的下一步。
