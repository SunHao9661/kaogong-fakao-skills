# 错题、来源与质量检查

## 错因

| 错因 | 信号 | 修复 |
| --- | --- | --- |
| 知识缺口 | 概念/公式不会 | 最小知识卡 |
| 题型识别 | 会方法但没看出 | 信号词训练 |
| 列式 | 对象、时间、单位错 | 重做“求什么—给什么” |
| 计算 | 列式对结果错 | 限时计算 |
| 阅读 | 否定、范围漏看 | 圈限制词 |
| 选项 | 算对选错 | 建干扰项标签 |
| 任务理解 | 申论答非所问 | 先写任务清单 |
| 材料加工 | 要点重复/无归类 | 段落标注和合并 |
| 时间 | 会做没做完 | 跳题阈值 |
| 形式不适配 | 面试结构或身份错 | 按公告形式重练 |

## 来源顺序

### 考试结构

1. 招录公告。
2. 报考指南。
3. 公共科目/专业科目大纲。
4. 官方样卷和评分说明。
5. 省级组织/人社/人事考试机构。

### 时政政策

1. 官方文件和会议公报。
2. 政府工作报告和统计公报。
3. 部委、地方政府官网。
4. 权威媒体完整转载。

### 法律

1. 现行法律和司法解释。
2. 官方释义。
3. 教材。

## 发送前

- 考试、年份、地区有没有丢。
- 是否把省考/事业单位默认成国考。
- 申论类别是否正确。
- 数值是否复算。
- 政策是否有日期。
- 专业科目是否有大纲。
- 模拟题是否标清。
- 面试形式是否来自公告。
