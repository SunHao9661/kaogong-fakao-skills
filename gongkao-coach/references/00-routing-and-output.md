# 路由、输出与证据

## 第一层：考试家族

| 类型 | 首先确认 | 不能默认 |
| --- | --- | --- |
| 国考 | 年份、职位类别、是否专业科目 | 只有行测申论两科 |
| 省考 | 省份、年份、公告、职位层级/类别 | 全国统一同卷 |
| 事业单位 | 统考/联考/单招、考试类别 | 公务员行测申论 |
| 选调/专项 | 招录公告、资格、科目、面试 | 普通公务员流程 |

## 第二层：任务模式

| 信号 | 模式 | 输出 |
| --- | --- | --- |
| 完整题目 | 单题讲解 | 结论、最短链、易错点 |
| 薄弱模块 | 专项 | 诊断、动作、训练量 |
| 日期与目标 | 计划 | 阶段、周任务、检查点 |
| 整套试卷 | 模考 | 结构、时限、答案分开 |
| 错题/成绩 | 复盘 | 错因、补弱、复测 |
| 材料与写作 | 申论/综合应用 | 得分点、材料依据、成文 |
| 面试题 | 面试 | 框架、示范、追问 |

## 第三层：事实范围

```text
考试：国考/省考/事业单位/专项
年份：
省份/地区：
职位/岗位类别：
科目：
事实：
来源：
发布日期：
```

没有这层信息时：

- 通用解题方法可以答。
- 科目结构、题量、分值、计划和模考不能假装确定。
- 政策与资格问题必须先查公告。

## 单题格式

```text
结论：
题型：
解题链：
易错点：
同类规律：
```

## 计划格式

```text
目标考试与岗位：
当前基线：
主攻顺序：
周计划：
限时任务：
检查点：
调整规则：
```

## 模考格式

```text
考试与年份：
职位类别：
组卷依据：
试卷：
独立答案：
解析：
时间与复盘表：
```

## 证据分级

| 等级 | 材料 |
| --- | --- |
| A | 当年官方公告、大纲、指南、样卷、成绩说明 |
| B | 用户提供且来源清楚的试卷/成绩 |
| C | 机构真题整理、回忆版 |
| D | 自编模拟题 |
| E | 必考、内部原题、包过 |

## 缺信息

- 只缺细节：给带假设版本。
- 缺考试类型：先问国考/省考/事业单位/专项。
- 缺年份和地区：不给官方式结构。
- 缺职位类别：不练确定申论卷种。
- 缺专业科目大纲：只做通用能力，不编专业考点。
