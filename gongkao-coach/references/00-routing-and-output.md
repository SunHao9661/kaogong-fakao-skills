## 先判模式

把请求归到一个主模式，必要时附加一个辅助模式：

| 信号 | 主模式 | 辅助模式 |
| --- | --- | --- |
| 有完整题干和选项 | 单题讲解 | 可附同类变式 |
| 上传整套材料但有多个小题 | 套题拆解 | 按题目逐项输出 |
| 说出薄弱模块或速度问题 | 模块训练 | 给诊断和训练量 |
| 要计划、安排、冲刺 | 备考规划 | 可附模考节奏 |
| 提供成绩、正确率、错题 | 复盘 | 可重排计划 |
| 问考试当天怎么做 | 考场策略 | 可给时间表 |
| 面试题、答题稿、追问 | 面试训练 | 可给示范和评分 |

如果用户只发“怎么办”“不会”“求提升”，先判断是否附有题目或成绩。没有任何具体材料时，给一个最小诊断表，不直接输出通用鸡汤。

## 单题回答

默认顺序：

1. **结论**：正确答案或明确作答方向。
2. **题型**：说明识别标志。
3. **最短解题链**：计算、材料定位或逻辑推理。
4. **易错点**：只给本题最关键的陷阱。
5. **同类规律**：一句可迁移的方法。

选项题按需增加：

- 让用户直接在选项上作答。
- 如果用户没主动要全解析，只解释正确项和一个最强干扰项。
- 用户明确要求全选项解析时，再逐项说明。

不确定时：

- 若题面缺失但可从上下文补足，先声明假设，再作答。
- 若关键数字、否定词或选项无法辨认，停止计算并指出缺失项。
- 无法唯一作答时给出分支答案，不硬凑一个选项。

## 模块训练

固定四段：

1. **速度/正确率诊断**：从读题、识别、列式、计算、选择中找出最慢的一步。
2. **固定动作**：给 3 到 5 步可重复流程。
3. **一刻钟示范**：用一个小例子演示动作。
4. **训练处方**：题量、限时、达标线和复测时间。

训练处方要能当天执行，例如“今天 2 组，每组 4 篇、限时 28 分钟；正确率达到 85% 再进入套题”，不要只写“多练”。

## 申论回答

### 归纳概括

```text
得分点：分条写结论
材料依据：段落/句意
作答：可用书面表达
```

### 综合分析

```text
观点判断 → 解释含义/原因 → 分析影响 → 落点
```

### 提出对策

```text
问题 → 原因 → 主体 → 动作 → 结果
```

### 大作文

默认先给“立意 + 三个分论点 + 每段材料落点 + 可用结构”。用户明确要求成文时，再写完整示范文，并标明“示范文”。

### 公文

先确认文种、身份、对象、目的、格式和字数。格式不确定时先说明所用版本，不冒充机关正式格式。

## 套题与模考

组卷前确定：

- 考试类型和地区/年份。
- 只做行测、申论，还是整套。
- 用户要真题拆解、真题变式，还是自编模拟。
- 难度、题量和限时。
- 答案与解析是否分开。

用户没有指定地区/年份时，可以按用户目标或常见结构搭一个训练框架，但必须标注“结构为训练假设，需按当年大纲替换”。

模考输出顺序：

1. 组卷说明和高频覆盖表。
2. 试卷本体。
3. 独立答案。
4. 解析。
5. 建议用时与复盘表。

## 训练计划

计划必须包含：

- 当前基线：分数、正确率、做题速度、薄弱模块。
- 目标与截止日期。
- 总分优先级：先补高收益、可训练的模块。
- 每周任务：学习、专项、限时、复盘、模考五类。
- 每日节奏：主训练块、碎片任务、休息与缓冲。
- 检查点：每周正确率、用时、错因变化。
- 调整规则：连续两次不达标时如何换练法。

条件不足时先生成一版“假设计划”，写明哪两个变量最影响结果，再请用户补充。

## 面试回答

结构化面试默认四段：

1. **观点**：一句话表态或确定目标。
2. **分析**：原因、影响、矛盾或工作重点。
3. **措施**：主体、动作、步骤、风险控制。
4. **收束**：结果导向的短句。

示范后给三条反馈：内容是否有抓手、结构是否清楚、语言是否像现场口头表达。不要只给模板。

## 质量标准

- 答案在前，解释在后。
- 有题面证据或计算过程，不做无依据判断。
- 材料题不凭常识补材料没有的信息。
- 建议具体到题量、时长和达标线。
- 所有预测、模拟和假设都显式标注。
