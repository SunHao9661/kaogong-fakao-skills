# 示例

## 四级分数不能换算

用户：

```text
四级 550，六级裸考大概能考多少？
```

回答：

```text
不能按四级分数推算六级分数。四级和六级使用不同常模、不同听力和写作任务，
分数不能线性换算。
四级 550 只说明基础相对稳，但仍需诊断：
1. 讲话/报道/讲座能否抓结构；
2. 六级阅读的长句和抽象替换能否处理；
3. 150 词写作能否在 30 分钟内完成有效论证；
4. 180—200 字翻译能否保持句法和信息完整。

最有效的是做一份结构正确的六级半程诊断，再估当前训练起点。
```

## 讲座听力

用户：

```text
六级讲座听力一长就跟丢。
```

回答：

```text
先改成“结构听力”，不要继续逐词硬听。
听开头找出问题和主题，中段只记：
第一点、第二点、转折、例子、结论。
笔记最多写名词、数字和箭头，不抄整句。
一段材料按三步练：
1. 原速做题；
2. 重听开头、转折和结论；
3. 合上原文，用三句话说讲座框架。

复测标准不是听懂每个词，而是能说出主题、两个支撑和一个结论。
```

## 多次不过

用户：

```text
六级考了三次：405、418、420，听力一直 110 多，怎么办？
```

回答：

```text
三次总分接近，听力稳定在低位，说明这不是一次状态波动。
先假设三场都按真实流程完成且成绩无异常：
1. 暂停每天刷整套；
2. 用 3 段长对话和 3 段讲座做精听，区分语音识别、结构、选项判断；
3. 阅读保持隔日限时，防止优势继续被挤占；
4. 写作翻译每周各两次，限时输出；
5. 两周后用一份六级听力整组复测。

如果听力仍没有变化，再看是否词汇反应速度过低，或笔记占用了听音注意力。
```

## 写作批改

用户：

```text
这篇六级作文只有 120 词，而且题目要求两问。
```

回答：

```text
先解决任务和词数，不先做高级词替换。题目两问就要各给明确回应；
主体两段分别承担两个问题，每段用“观点—解释—例子—回扣”展开。
补到 150 词以上应来自内容和论证，不是堆结尾空话。
我会标出必须补的两处任务缺口，然后重写其中一个主体段作示范。
```
