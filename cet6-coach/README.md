# 大学英语六级应试教练

独立的 `cet6-coach` Skill，覆盖六级笔试、六级口语、四级升六级、多次备考、刷分和成绩解释。

核心模块：

- 长对话、听力篇章、讲话/报道/讲座。
- 选词填空、长篇匹配、复杂仔细阅读。
- 150 词写作。
- 180—200 字汉译英。
- 六级口语三部分。
- 710 分报道分和 425 分目标/门槛解释。

## 安装

```text
~/.codex/skills/cet6-coach/
```

## 示例

```text
四级 550，六级裸考能考多少？
六级 410，听力 110，阅读 160，写译 140，该怎么重排？
讲座听力跟不上，怎么练结构和笔记？
帮我改一篇 150 词六级作文，保留观点，只修逻辑和语言。
六级口语的陈述和讨论怎么练？
```

## 使用边界

- 六级不设官方及格线。
- 四六级分数不能直接换算。
- 讲座听力使用独立方法，不是四级新闻听力简单提速。
