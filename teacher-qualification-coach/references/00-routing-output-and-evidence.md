# 路由、输出与证据

## 先判阶段

| 信号 | 阶段 | 首轮交付 |
| --- | --- | --- |
| “能不能报”“学历够不够” | 报考资格 | 核验项和官方入口 |
| “选小学还是初中”“选哪个学科” | 类别选择 | 科目组合、用途、限制 |
| “科目一/二/三怎么学” | 笔试 | 模块、题型、输出训练 |
| “教案/试讲/结构化” | 面试 | 目标、过程、互动、答辩 |
| “有一科没过” | 重考 | 有效期、科目组合、时间倒排 |
| “合格证明/普通话/认定” | 认定 | 条件、材料、属地 |
| “教师招聘/特岗” | 范围外 | 明确不属于教资默认范围 |

## 最小信息

```text
省份：
考试批次：
目标类别：
学段：
学科：
当前阶段：
已过科目与成绩：
剩余时间：
```

仅问一个通用答题技巧时，不需要省份；涉及资格、报名和认定时，省份不可省。

## 证据分级

| 等级 | 材料 | 使用 |
| --- | --- | --- |
| A | 教育部教育考试院、省级教育考试机构、官方考试标准和大纲 | 规则依据 |
| B | 用户提供且可确认年份、学段、科目的试卷或答案 | 可分析 |
| C | 机构真题汇编、考生回忆版 | 训练参考 |
| D | 自编题、自编试讲题 | 标自编模拟 |
| E | 包过、内部原题、万能逐字稿 | 不作为依据 |

## 输出格式

### 笔试

```text
题型与考点：
阅读/审题：
答题骨架：
示范：
易错点：
复测：
```

### 面试

```text
题目：
目标：
重点：
难点：
教学过程：
板书：
互动与评价：
可能追问：
改进点：
```

### 资格或认定

```text
当前能确认：
仍需核验：
官方入口：
材料清单：
时间风险：
```

## 真实性

- 考试结构、报告分和有效期是官方规则。
- 具体日程、属地资格和认定材料是年度/省级快照。
- 材料分析和教学设计没有唯一逐字答案，反馈按评分维度。
- 模拟教案必须标“训练示例”，不能称官方范文。
