# 计划、模考、错题与重考

## 计划所需信息

- 目标类别、学段、学科。
- 考试日期。
- 已过科目和有效期。
- 各科当前水平。
- 每日/每周时间。
- 是否同时准备面试。

## 笔试阶段

### 诊断

每科做一份与目标学段一致的限时材料，记录：

- 单选题正确率。
- 材料分析是否有理论和事实。
- 简答/辨析是否要点化。
- 教案是否完整。
- 作文或论述是否能快速立意。

### 主建设

- 科目一：选择题、材料分析、作文并行。
- 科目二：框架、简答、材料分析、教学设计。
- 科目三：学科知识、课程标准、教学设计、实施评价。

### 整合与冲刺

- 按真实时间做整科限时。
- 重写失分材料。
- 控制新增资料，保留稳定输出动作。

## 面试阶段

- 每周固定数量结构化题。
- 每周完整试讲。
- 至少一次全流程模拟：抽题、备课 20 分钟、面试 20 分钟。
- 回看录音，只改关键动作。

## 错因

| 错因 | 修复 |
| --- | --- |
| 概念混淆 | 对比表 + 3 题辨认 |
| 法律版本旧 | 查现行文本 |
| 简答无要点 | 先列短语纲 |
| 材料无理论 | 练“理论—事实—措施” |
| 教案无目标 | 用可观察目标重写 |
| 课堂无互动 | 设计提问和反馈 |
| 时间失控 | 分段计时 |

## 单科重考

先做时间表：

```text
已过科目及到期日：
未过科目：
下一次笔试：
面试是否可报：
认定计划：
```

规则：

- 在有效期内优先处理未过且关键的科目。
- 面试只能在笔试相应条件满足后报名。
- 更换学段或学科前，确认可复用科目。
- 具体成绩状态、报名和审核以系统及省级公告为准。

## 质量检查

- 计划不是平均分配所有科目。
- 每周有书面或口述输出。
- 复盘有具体错因和复测。
- 面试训练有完整流程，不只有背题。
