# 面试：结构化、试讲与答辩

## 官方时间

- 备课 20 分钟。
- 面试 20 分钟。

具体环节、顺序和评分点以对应面试大纲、准考证和当次公告为准。

## 面试准备流

```text
抽题/看题
→ 判断学段学科
→ 快速确定目标与重难点
→ 写教学提纲
→ 设计活动与提问
→ 预设板书
→ 练习开场、收束和答辩
```

## 结构化问答

常见类型：

- 综合分析。
- 教育情境处理。
- 人际沟通。
- 组织活动。
- 应急应变。
- 职业认知和岗位匹配。

默认结构：

```text
先定目标或原则
→ 分析关键矛盾
→ 2—3 条具体措施
→ 结果、反思或机制
```

回答要符合教师身份、学生身心发展规律和学校程序，不能越权承诺。

## 试讲

### 目标

目标要能观察：

```text
学生能够……
通过……活动
达到……程度
```

### 过程

```text
导入：引出问题/激活经验
新授：任务、提问、示范、探究
练习：分层或变式
总结：学生回顾和教师提炼
评价：过程反馈
作业：与目标一致
```

### 互动

- 提问后给思考时间。
- 预设不同层次回答。
- 评价指出具体优点和改进，不用“很好，请坐”敷衍。
- 没有真实学生时也要体现倾听和回应。

### 板书

- 与教学主线一致。
- 不写满黑板，不用无关装饰。
- 语文、数学、英语、音乐、体育等学科板书功能不同。

## 答辩

常见追问：

- 为什么这样定目标？
- 重难点依据是什么？
- 某个环节如何照顾差异？
- 如果学生回答错误怎么办？
- 如何评价目标是否达成？

回答：

```text
直接回应
→ 给教学依据
→ 说具体动作
→ 说明结果检查
```

## 模拟流程

1. 限时读题和写提纲。
2. 完整试讲。
3. 录音或录像。
4. 按目标、结构、互动、语言、板书、时间反馈。
5. 只改一到两个最关键问题，再讲一次。

## 质量检查

- 学段和学科匹配。
- 目标、过程、评价一致。
- 教师语言自然、学生活动具体。
- 没有背诵整篇“万能稿”。
- 答辩回答不逃避问题。
