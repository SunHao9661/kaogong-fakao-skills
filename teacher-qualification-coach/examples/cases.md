# 示例

## 教师招聘误触发

用户：

```text
我想考小学语文教师编，面试怎么准备？
```

回答：

```text
这属于教师招聘/教师事业编，不是中小学教师资格考试的默认范围。
招聘面试形式由当次公告和地区决定，可能包括试讲、结构化、答辩或技能展示。
我需要招聘地区、年份和岗位公告，才能按真实流程训练。
另外，教师资格证只是多数岗位的资格条件之一，不能替代招聘考试要求。
```

## 科目三不能共用模板

用户：

```text
初中数学和初中语文的科目三教案可以共用一套吗？
```

回答：

```text
不能。两科都可能有教学设计，但学科逻辑不同：
数学要体现概念形成、推理、例题层次和数学思想；
语文要体现文本细读、语言活动和阅读/表达目标。
需要分别为两科读取对应大纲，并把目标、重难点、活动和评价统一起来。
```

## 报告分解释

用户：

```text
教资笔试 68 分，是不是卷面只差 2 分？
```

回答：

```text
不是。68 是报告分，不等于原始卷面 68 分，也不是原始卷面只差 2 分。
当前口径是报告分满分 120、70 分及以上合格。
能否复核、如何复核要看当次省级公告。
```

## 单科重考

用户：

```text
我小学科目一过了，科目二没过，下一步怎么排？
```

回答：

```text
先确认科目一成绩的具体到期日和下一次笔试时间。
下次重点准备科目二，同时用少量时间保持科目一的法律、材料分析和写作手感。
报名条件、成绩状态和是否需要重新注册以系统及省级公告为准。
如果目标是尽快面试，倒排到成绩有效期内的最近一次笔试。
```

## 完整试讲大纲

用户：

```text
给一个初中英语阅读课的试讲框架。
```

回答：

```text
目标：学生能通过略读获取主旨，通过寻读找到关键信息，并用目标表达复述文本。
重点：语篇结构和关键信息。难点：用英语概括并表达理由。
过程：
1. 情境导入，引出主题。
2. 略读，匹配段落主旨。
3. 寻读，完成信息表。
4. 语言聚焦，操练目标表达。
5. 两人活动，基于文本问题表达观点。
6. 学生总结，教师补充。
评价：用信息完整度、表达清楚度和合作参与反馈。
板书：主题—结构—目标表达。
追问：如何照顾阅读速度较慢的学生？
```
