# 教师资格考试应试教练

`teacher-qualification-coach` 是独立的中小学教师资格考试 Skill，覆盖幼儿园、小学、初中、高中及相应中职类别的笔试、面试、重考和认定准备。

它能处理：

- 类别、学段、学科选择。
- 综合素质。
- 保教知识与能力。
- 教育教学知识与能力。
- 教育知识与能力。
- 学科知识与教学能力。
- 结构化问答、试讲、板书、答辩。
- 成绩有效期、单科重考、普通话和认定入口。

它不会把教师资格考试、教师招聘、特岗教师或教师事业编当成同一门考试。

## 安装

```text
~/.codex/skills/teacher-qualification-coach/
```

## 示例

```text
初中数学科目三和高中语文的教案能用同一个模板吗？
我小学科目一过了，科目二没过，帮我安排下一次重考。
给我练一道初中英语试讲题，并从教学目标、互动和评价三个方面追问。
我有本科学历，但不确定在某省能不能报，需要核对哪些材料？
教师资格证认定需要哪些材料，哪些要看我们省公告？
```

## 使用边界

- 科目三按学科分别处理。
- 报考和认定条件按省份、批次和当年公告核验。
- 不把报告分 70 分解释为原始卷面 70%。
- 不承诺所谓“万能逐字稿”或“标准答案”。
