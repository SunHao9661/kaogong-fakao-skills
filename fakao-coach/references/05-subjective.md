# 法考主观题

## 先读问题

先看每问：

- 请求权。
- 罪名和形态。
- 程序是否合法。
- 证据能否采信。
- 裁判/复议/决定是否正确。
- 文书或论述要求。

再带问题读材料。

## 事实表

```text
主体关系：
关键行为：
意思表示：
时间顺序：
程序阶段：
争议请求：
已知/未知：
```

多主体先画关系，多问题逐问回答。

## 四段法

### 1. 结论

直接回答。

### 2. 争点

写决定结论的矛盾。

### 3. 规则

先写规则内容，再写已核实条号。没有核实条号只写规范名称和规则。

### 4. 事实适用

每个要件对应一个题干事实，最后回到问题。

## 请求权

```text
谁向谁
→ 请求什么
→ 基础关系
→ 构成要件
→ 抗辩/解除/抵销/时效
→ 范围
```

多个请求权判断能否并存、择一或顺位。

## 刑法案例

按人、行为、阶段：

```text
被告人
→ 行为
→ 法益
→ 客观要件
→ 主观要件
→ 阻却事由
→ 形态
→ 共犯/罪数
→ 处罚
```

## 程序案例

- 主体。
- 阶段。
- 行为。
- 权限。
- 程序。
- 期限/救济。
- 后果。

区分可补正、撤销、确认违法、驳回等后果。

## 法律文书

先确认：

- 起诉状、答辩状、代理词。
- 判决、裁定、调解。
- 起诉书、不起诉决定。
- 复议申请、行政起诉状。

通用骨架：

```text
标题
当事人/机关
请求或决定
事实与理由
法律依据
落款日期
```

不补造题干没有的姓名、地址、日期和证据。

## 论述

```text
观点
→ 规范/制度基础
→ 论证
→ 反例或边界
→ 结论
```

不堆口号。

## 客观题与主观题区别

客观题重识别和逐项排除；主观题要让阅卷者看到：

- 问了什么。
- 你答什么。
- 依据什么。
- 对应哪些事实。
- 有没有例外。

## 2026 机考

- 主观题 240 分钟，180 分。
- 原则上机考。
- 符合条件可申请纸笔。
- 少数民族语言作答按规则纸笔。
- 统一提供电子法律法规。
- 有选作题时择一作答。

## 时间

- 先分每题时间。
- 每问先结论。
- 短段落、编号。
- 最后一题留检查。

## 批改

先看得分点，再看漏点，最后只重写关键段。无官方法评分细则时不给假装精确分数。
