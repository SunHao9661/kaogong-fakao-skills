# 法考主观题

## 第一步：先读问题

不要先通读材料再背知识。先看每个问题问什么，再带着问题读事实：

- 问请求权基础。
- 问罪名与形态。
- 问程序是否正确。
- 问证据能否采信。
- 问判决/裁定是否合法。
- 问法律文书如何写。

把材料中的时间、主体、行为、程序节点和请求标出来。

## 事实拆解

```text
主体关系：
关键行为：
意思表示：
时间顺序：
程序阶段：
争议请求：
已知/未知事实：
```

多主体题先画关系，不直接列法条。多问题题逐问作答，避免全部写成一段。

## 主观题四段法

### 1. 结论

用一句短句直接回答：

```text
甲可以请求乙承担违约责任。
丙的行为不构成犯罪既遂，成立犯罪未遂。
该行政处罚决定存在程序违法。
```

### 2. 争点

写出决定结论的核心矛盾：

```text
争点在于合同是否已经成立并使甲取得请求权。
争点在于甲是否具有非法占有目的，以及取得财物的方式。
```

### 3. 法律依据

先写规则内容，再写已核实条号。未核实条号时只写规范名称和规则：

```text
依据民法典关于合同成立、违约责任和损失赔偿的规则……
```

不要编造“第几百条”来制造权威感。

### 4. 事实适用与结论

逐一对应构成要件：

```text
要件 1 ↔ 材料事实
要件 2 ↔ 材料事实
因此……
```

最后回到题目问法，检查有没有漏问、答非所问或多写对方没问的内容。

## 请求权分析

```text
谁向谁提出什么请求
→ 基于合同、物权、侵权、不当得利等
→ 构成要件
→ 抗辩、解除、抵销、时效
→ 责任范围和数额
```

多个请求权并存时，先判断是否可以选择，再判断能否同时主张。

## 刑法案例

按人、按行为、按阶段分点：

```text
被告人 → 行为 → 保护法益 → 客观要件 → 主观要件
→ 违法阻却/责任阻却 → 未遂/中止/既遂 → 共犯/罪数
```

不要把“行为构成犯罪”与“应否处罚”“如何量刑”混在一起。

## 程序案例

至少写清：

- 主体。
- 阶段。
- 行为。
- 权限和程序。
- 期限或救济。
- 后果。

程序错误要区分可补正、应撤销、应确认违法或不需要救济等不同后果。

## 法律文书

先确认文种和格式：

- 起诉状、答辩状、代理词。
- 判决书、裁定书、调解书。
- 起诉书、不起诉决定书。
- 行政复议申请书、行政诉讼起诉状。

通用骨架：

```text
标题
当事人/机关信息
请求事项或决定
事实与理由
法律依据
落款与日期
```

文书中的事实只能来自题干；不确定的姓名、地址、日期和证据名称用题干已有信息，不补齐不存在的事实。

## 论述题

结构：

```text
观点 → 规范/制度基础 → 论证 → 反例或限制 → 结论
```

避免只堆政治口号或背书式罗列。涉及当前理论政策时，以当年考试大纲和权威文件为准。

## 时间与卷面

- 先分配每题时间，给最后一题留检查空间。
- 每问先写结论，再补论证。
- 使用短段落和编号。
- 不在一道低把握题上写超时长文。
- 最后检查：题号、问法、主体、结论、法源是否一致。

具体考试时长和题量以当年官方公告、大纲和样卷为准，不把旧年份安排当固定规则。
