# 路由与输出

## 先判题型

| 信号 | 模式 | 主要输出 |
| --- | --- | --- |
| 单选、多选、不定项 | 客观题解析 | 答案、争点、规则、逐项判断 |
| 长材料、多个主体、多个问题 | 案例分析 | 关系、争点、规则、适用、结论 |
| 主观题答案、答题纸 | 批改 | 得分点、漏点、示范、复测 |
| 某一科反复错 | 模块训练 | 知识树、识别表、练习 |
| 要完整模拟 | 组卷 | 题、答案、解析、评分 |
| 要长期/冲刺计划 | 规划 | 阶段、周任务、检查点 |
| 问考场节奏 | 策略 | 顺序、时间、跳题与回看 |

## 读取事实

先把题干压缩为事实表：

```text
主体：
时间线：
关键行为/意思表示：
程序节点：
请求/被指控行为：
争议事实：
```

不要一开始就背法条。先确认法律关系，否则会出现“知识背对、对象用错”。

## 客观题格式

```markdown
**答案：** A/C

**争点：**一句话

**规则：**法律名称与规则；条号未核实时不写具体序号。

**选项判断：**
- A：……
- B：……

**易错点：**最强干扰项为何像对但不对。
```

多选题默认逐项判断。只解释正确项不足以证明其余选项错误。

## 主观题格式

```markdown
**结论：**先回答“支持/不支持、有罪/无罪、行为是否合法”等核心问题。

**法律关系与争点：**分主体、分请求。

**法律依据：**规范名称＋规则内容；必要时再写已核实条号。

**事实适用：**逐一对应构成要件或程序条件。

**结论：**回到题目问法，不漏问。
```

## 存在分支时

当题干事实不足或同一规则存在成立/不成立条件时，用：

```text
如果事实 A，则结论甲；
如果事实 B，则结论乙；
目前题干只支持……
```

不要为了给唯一答案而补入题干没有的关键事实。

## 批改格式

1. **总分/等级**：只有用户给出评分规则时才精确给分；否则用“稳健、需补强、风险高”。
2. **得分点清单**：已写到什么。
3. **漏点**：缺哪一争点、规则或事实对应。
4. **性质判断**：知识错误、法律关系错误、程序错误、事实遗漏、表达不清。
5. **重写示范**：只重写最关键的 1 到 2 段。
6. **复测动作**：下一次用什么题验证。

## 计划与模考

- 组卷前确认客观题/主观题、科目、难度、题量、限时。
- 没有当年考试格式时按训练假设组卷，并标明“需按当年大纲核验”。
- 计划需要当前基础、剩余时间、每日可用时间、目标。
- 计划要给“背、练、写、复盘”四类任务，不能只有看课。

## 质量标准

- 题目问什么就先答什么。
- 结论、规则、事实三者不能跳接。
- 法条序号、程序期限和机关权限有来源才写精确值。
- 自编题、变式题和官方真题清晰区分。
