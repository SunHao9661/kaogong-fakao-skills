# 路由、输出与事实表

## 先判问题

| 信号 | 模式 | 输出 |
| --- | --- | --- |
| 报名条件、学历、应届、放宽 | 资格 | 条件、例外、官方入口 |
| 客观题或选项 | 客观题 | 答案、争点、规则、逐项判断 |
| 长案例、多个问题 | 主观题 | 分主体、分请求、分阶段 |
| 某科反复错 | 模块 | 框架、对比、练习 |
| 完整模拟 | 模考 | 客观两卷或主观一卷 |
| 成绩和授予资格 | 年度流程 | 线、有效期、时间 |
| 新旧法 | 法源适用 | 行为时间、规则版本、过渡 |

## 事实表

```text
考试年度：
客观/主观：
主体：
时间线：
关键行为/意思表示：
程序阶段：
争议请求：
已知/未知事实：
行为发生时点：
```

不要先背法条。先确认法律关系和适用时间。

## 客观题格式

```text
答案：
争点：
规则：
选项判断：
易错点：
```

多选和不定项逐项判断。只解释正确项不足。

## 主观题格式

```text
结论：
法律关系与争点：
法律依据：
结合事实的论证：
例外/反方观点：
回到问题：
```

没有核实条号时只写规范名称和规则，不编“第几百条”。

## 事实不足

```text
如果事实 A，结论甲；
如果事实 B，结论乙；
题干目前只能支持……
```

不为了唯一答案补入题干没有的关键事实。

## 法源标签

每个规则尽量在内部标为：

- 法律。
- 行政法规。
- 司法解释。
- 指导性案例。
- 官方释义。
- 教材/通说。
- 模型推演。

## 真实性

- 官方真题只有在用户提供或可核实来源时标注。
- 2026 法考不公布试题及参考答案。
- 回忆版、机构整理和自编案例分层。
- 不写“必考”“命题人内部题”。

## 完成标准

- 核心问题先回答。
- 规则与事实逐一对应。
- 多主体和多请求分开。
- 无未核实精确数字。
- 结论与规范版本一致。
