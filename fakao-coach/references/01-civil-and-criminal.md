# 民法与刑法

## 民法总则与请求权

先确定主体、权利、义务和责任，再选请求权基础。常见步骤：

```text
谁向谁 → 请求什么 → 基于合同、物权、侵权、不当得利或其他关系
→ 构成要件 → 抗辩/例外 → 责任方式与范围
```

### 民事主体与代理

- 判断民事权利能力和行为能力。
- 限制行为能力人实施的行为，需看是否与年龄、智力相适应以及是否经法定代理人同意或追认。
- 代理要有授权外观、代理权限和利益归属。
- 无权代理、表见代理、自己代理和双方代理要分别处理。
- 追认、撤销、催告和相对人善意与否可能改变结果。

### 民事法律行为的效力

依次检查：

1. 主体是否适格。
2. 意思表示是否真实。
3. 是否违反强制性规定或公序良俗。
4. 是否存在无效、可撤销、效力待定等特别规则。

可撤销与无效不能混用。撤销权是否已经行使、是否超过期间，是答题必须检查的时间点。

### 合同

#### 成立与生效

- 要约与承诺是否形成合意。
- 是否需要特定形式、批准、登记或交付。
- 合同成立不等于当然生效，生效条件要单独判断。
- 格式条款、免责条款、预约和本约要分开。

#### 履行与违约

- 履行主体、期限、地点、方式。
- 同时履行抗辩、先履行抗辩、不安抗辩。
- 违约形态：不履行、迟延履行、瑕疵履行。
- 违约责任：继续履行、采取补救措施、赔偿损失、违约金。
- 检查减损义务、可预见规则、定金与违约金关系。

#### 解除

法定解除、约定解除和协商解除分别判断；解除权的行使方式、期限和法律后果要写清。

### 物权

- 不动产登记与动产交付。
- 所有权、用益物权、担保物权和占有。
- 善意取得须检查无权处分、受让人善意、合理价格和交付/登记等要件。
- 抵押、质押、保证等担保关系注意主合同效力、担保范围和顺位。

### 侵权

先看归责原则，再查构成要件：

```text
权利受侵害 + 行为 + 因果关系 + 过错/法定归责事由
```

特殊主体、特殊活动、产品责任、医疗损害、环境污染、饲养动物等有专门规则，先确认类型再套规则。

### 婚姻家庭与继承

- 婚姻效力、夫妻共同财产与个人财产。
- 离婚时的财产分割、债务承担、子女抚养。
- 法定继承、遗嘱继承、遗赠和遗赠扶养协议。
- 继承顺序与遗嘱效力要按时间与形式核验。

## 刑法

### 定罪框架

```text
构成要件该当性 → 违法性 → 有责性
```

实践中可按：

1. 行为对象和结果。
2. 行为与结果之间的因果关系。
3. 故意、过失及认识错误。
4. 正当防卫、紧急避险等违法阻却事由。
5. 责任能力、违法性认识可能性和期待可能性。

### 不真正不作为

先判断是否具有作为义务，再判断是否具有履行可能和结果避免可能。义务来源、等价性和因果关系缺一项都可能影响结论。

### 犯罪形态

- 预备：为犯罪准备工具、制造条件。
- 未遂：已经着手，因意志以外原因未得逞。
- 中止：自动放弃或自动有效防止结果。
- 既遂：按具体犯罪的既遂标准判断，不只看是否获利。

### 共同犯罪

检查共同故意、共同行为和分工。主犯、从犯、胁从犯、教唆犯以及实行过限要分别处理。一人既遂不等于所有人当然对同一结果负责，仍需判断共同犯罪范围。

### 罪数与竞合

区分法条竞合、想象竞合、牵连关系和数罪。先判断行为个数和保护法益，再选择处断规则。

### 重点罪名识别

答题时先找核心行为：

- 财产犯罪：取得方式、被害人意思、占有转移。
- 人身犯罪：行为对象、结果、故意内容。
- 贪污贿赂：主体身份、职务便利、利益输送。
- 公共安全犯罪：危险是否具体、是否造成后果。
- 经济犯罪：非法占有目的、交易外观、行政违法与刑事犯罪边界。

不要只凭罪名关键词；同一事实可能同时涉及民事无效、行政违法和刑事责任。
