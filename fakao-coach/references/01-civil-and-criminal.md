# 民法与刑法

## 民法与请求权

先确定主体、权利、义务和责任，再选请求权基础：

```text
谁向谁
→ 请求什么
→ 合同、物权、侵权、不当得利、无因管理等
→ 构成要件
→ 抗辩/例外
→ 责任方式和范围
```

不要把“民法总则”作为现行独立法源名称。现行民事基本规则以民法典及配套法源核验。

### 民事主体与代理

- 权利能力、行为能力。
- 法定代理、委托代理。
- 无权代理、表见代理。
- 自己代理、双方代理。
- 追认、催告、撤销和相对人善意。

### 民事法律行为

1. 主体。
2. 意思表示。
3. 强制性规定和公序良俗。
4. 无效、可撤销、效力待定。

撤销权是否行使、期间是否经过是必查事实。

### 合同

- 成立与生效。
- 要约、承诺、预约和本约。
- 格式条款。
- 履行抗辩。
- 违约形态。
- 解除。
- 违约责任、定金、违约金和损失赔偿。
- 减损规则和可预见规则。

### 物权与担保

- 不动产登记。
- 动产交付。
- 所有权、用益物权、担保物权和占有。
- 善意取得要件。
- 抵押、质押、保证。
- 主合同、担保范围、顺位和抗辩。

### 侵权

```text
受保护权益
→ 行为
→ 因果关系
→ 过错或法定归责
→ 免责/减责
→ 责任方式
```

产品、医疗、环境、饲养动物等先识别特殊规则。

### 婚姻家庭与继承

- 婚姻效力。
- 夫妻共同财产与债务。
- 离婚、抚养和财产分割。
- 法定继承、遗嘱、遗赠和遗赠扶养协议。

## 刑法

### 定罪

```text
构成要件
→ 违法性
→ 有责性
```

逐项检查：

- 对象、行为、结果。
- 因果关系。
- 故意、过失和认识错误。
- 正当防卫、紧急避险。
- 责任能力和期待可能性。

### 不作为

先判作为义务，再判履行可能、结果避免可能和等价性。

### 犯罪形态

- 预备。
- 未遂。
- 中止。
- 既遂。

按具体犯罪的既遂标准，不只看是否获利。

### 共同犯罪

- 共同故意和共同行为。
- 主犯、从犯、胁从犯、教唆犯。
- 实行过限。
- 一人既遂不等于所有人对全部结果负责。

### 罪数与竞合

先判断行为个数和保护法益，再处理法条竞合、想象竞合、牵连和数罪。

### 重点罪名

- 财产犯罪：取得方式、占有转移、被害人意思。
- 人身犯罪：对象、结果、故意内容。
- 贪污贿赂：主体、职务便利、利益输送。
- 公共安全：具体危险、后果。
- 经济犯罪：非法占有目的、交易外观、行刑边界。

## 输出提醒

- 民事、行政、刑事可能交错，分别判断。
- 规范名称和规则先于条号。
- 条号、期限和司法解释未核实不写精确值。
