# 批改、错题与法源核验

## 错因

| 错因 | 现象 | 修复 |
| --- | --- | --- |
| 规则遗忘 | 不知道考点 | 最小规则卡 |
| 规则混淆 | 相似制度错位 | 对比表 |
| 要件漏项 | 只写结论 | 要件清单 |
| 事实漏读 | 漏时间、身份、程序 | 事实表 |
| 关系错位 | 找错请求权/罪名 | 关系图 |
| 程序阶段错 | 主体或救济错 | 程序时间线 |
| 条号/期限错 | 记忆数字 | 查官方文本 |
| 表达无争点 | 写很多但不对题 | 四段法压缩 |

## 客观题卡

```text
题目来源：
考试年度：
试卷/科目：
争点：
我的答案/正确答案：
错因：
规则：
最强干扰项：
相似规则：
24 小时复测：
7 天复测：
```

## 主观题批改

1. 每问是否答全。
2. 争点是否准确。
3. 规则是否正确。
4. 事实是否对应要件。
5. 结论是否明确。
6. 卷面是否可读。

先给得分点，再给漏点，最后重写关键段。

## 法源优先级

1. 现行法律、行政法规、司法解释。
2. 官方指导性案例和典型案例。
3. 官方释义和权威教材。
4. 学术观点。

教材观点不能写成法条。

## 精确引用

写条号前查：

- 法名。
- 是否现行。
- 条号与内容。
- 适用时间。
- 司法解释。
- 过渡条款。

不能核实就不写条号。

## 新法旧法

```text
行为/程序发生时间
→ 当时有效法
→ 司法解释和过渡规则
→ 当前法另行回答
```

不要用“现在法”直接覆盖题干历史事实。

## 来源写法

```text
截至 YYYY-MM-DD，依据《法名》关于……的规则。
```

观点写“教材/通说认为”；案例写“某类案例中法院认为”。

## 发送前

- 先给答案。
- 主体和请求分开。
- 解释最强干扰项。
- 无未核实条号/期限。
- 主观题有规则事实对应。
- 模拟题已标。
- 有复测动作。
