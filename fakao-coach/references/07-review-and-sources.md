# 批改、错题与法源核验

## 错因分类

| 错因 | 现象 | 修复 |
| --- | --- | --- |
| 规则遗忘 | 完全不知道考点 | 建最小规则卡 |
| 规则混淆 | 相似制度放错 | 做对比表 |
| 要件漏项 | 只写结论，未逐项适用 | 用要件清单重写 |
| 事实漏读 | 漏掉时间、身份、程序 | 先做事实表 |
| 法律关系错位 | 找错请求权或罪名 | 重画关系图 |
| 程序阶段错误 | 主体、阶段或救济错 | 画程序时间线 |
| 条号/期限错误 | 记忆数字不实 | 查官方文本 |
| 表达问题 | 写太多但没有争点 | 用四段法压缩 |

## 客观题错题卡

```text
题目来源：
科目/题干争点：
我的答案 / 正确答案：
错因：
正确规则：
最强干扰项：
相似规则：
24 小时复测：
7 天复测：
```

## 主观题批改

按以下顺序批：

1. **问题是否答全**：每个小问是否都有结论。
2. **争点是否准确**：是否抓住决定结论的法律关系。
3. **规则是否准确**：法律名称、规则和例外是否对应。
4. **事实是否适用**：是否把题干事实放到构成要件或程序条件中。
5. **结论是否清楚**：是否有明确结论和责任/程序后果。
6. **卷面是否可读**：编号、段落和法源是否方便阅卷。

批改反馈先给得分点，再给漏点，最后给重写。不要把整篇答案全部重写，优先改决定得分的一到两段。

## 法源优先级

1. 现行法律、行政法规和有权机关发布的司法解释。
2. 官方指导性案例、最高法和最高检正式发布的典型案例。
3. 官方释义、权威教材。
4. 学术观点。

不能把教材观点写成法律条文，也不能把政策文件直接当成裁判规范。

## 精确引用规则

写具体条号前检查：

- 法规名称是否准确。
- 文本是否现行有效。
- 条号是否与内容对应。
- 考试时点是否适用该版本。
- 是否有司法解释进一步改变适用。

不能核实就不写条号。可以写“依据民法典关于……的规则”，并在需要时提醒用户核对官方文本。

## 时效规则

同一问题出现新法、旧法或司法解释变化时：

```text
确定行为/程序发生时间
→ 确定适用法
→ 检查过渡条款
→ 再判断结论
```

不要用“现在法”直接覆盖“题干发生时法”。

## 来源写法

```text
截至 YYYY-MM-DD，依据《法名》关于……的规则（条号如已核实）。
```

对观点写“教材/通说认为”，对裁判写“某类案例中法院认定”，不混成法律。

## 发送前检查

- 是否先给答案/结论。
- 每个主体和请求是否分别回答。
- 是否解释了最强干扰项。
- 是否有未核实的条号、期限或机关权限。
- 主观题是否有规则与事实的对应。
- 模拟题是否标为自编。
- 是否给了一个可以立即执行的复测动作。
