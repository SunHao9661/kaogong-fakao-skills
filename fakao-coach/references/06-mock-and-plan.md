# 模拟卷与备考计划

## 组卷原则

组卷前确定：

- 客观题、主观题或混合。
- 科目范围。
- 题量、难度、限时。
- 题目来源：官方真题、真题变式或自编案例。
- 是否要答案解析和评分点。

卷首必须写清真实性：

```text
本卷为自编训练模拟，不是官方真题；正式题型、科目和分值以当年官方公告、大纲和样卷为准。
```

## 客观题组卷

每道题给出：

- 题型：单选、多选或不定项。
- 科目和考点。
- 事实和选项。
- 答案。
- 逐项解析。
- 法源类别：法律、司法解释、学理或程序规则。

多选和不定项不能只解释正确项，要说明每个干扰项错在哪里。

## 主观题组卷

每道案例至少包含：

- 两到四个主体。
- 可识别的时间线。
- 一个民事/刑事/行政核心争点。
- 一到两个可以影响结论的细节。
- 分问明确的题目。

答案分为：

```text
结论 → 争点 → 规则 → 事实适用 → 可接受的分支
```

评分点必须区分必答得分点和加分论证点。没有官方评分标准时不声称为官方分值。

## 计划基线

需要：

- 客观题各科当前正确率。
- 主观题是否开始练、是否能写出争点和法源。
- 剩余天数。
- 每日可用时间。
- 目标分数或通过目标。

缺少数据时，先给“假设计划”，写清按什么基础估算。

## 阶段设计

### 1. 框架期

- 建立学科目录。
- 把规则、例外、程序节点、易混概念做成卡片。
- 先做少量原题验证理解。

### 2. 专项期

- 按科目和题型分组。
- 客观题练识别和逐项判断。
- 主观题从短答案开始，逐步扩展到完整案例。

### 3. 整合期

- 跨科目混合。
- 同一事实涉及多个部门法时，练切换。
- 主观题限时写完整答案。

### 4. 模考期

- 客观题限时卷。
- 主观题按题组限时。
- 复盘“规则错误、事实漏读、请求漏答、表达过长”。

### 5. 收口期

- 回看错题卡和高频规则。
- 保持每天短时训练。
- 不在最后阶段大规模增加新资料。

## 12 周参考

| 周次 | 客观题 | 主观题 |
| --- | --- | --- |
| 1 | 基线卷 + 错因分类 | 识别题型和答题格式 |
| 2-4 | 民法、刑法、程序法主框架 | 每周 2 个短案例 |
| 5-6 | 行政、商经知、理论、三国补框架 | 每周 3 个跨科案例 |
| 7-8 | 混合客观题专项 | 完整主观题限时 |
| 9 | 第一次客观题模考 | 主观题卷面复盘 |
| 10 | 按错因补弱 | 法律文书/论述专项 |
| 11 | 第二次客观题模考 | 第二次主观题限时 |
| 12 | 错题和短暂回忆 | 轻量重写 + 节奏调整 |

如果只剩 4 周，优先保“高频规则 + 两套限时 + 逐题复盘”，不要试图把全部资料重看一遍。

## 检查点

- 客观题：正确率、题干识别时间、选项判断完整度。
- 主观题：是否写出争点、法源、事实对应和结论。
- 每周至少一次限时，不只看学习时长。
- 复盘两次后仍无改善的模块，缩减资料范围，改做短题和重写。
