# 民事、刑事、行政程序与证据

程序题先画时间线。主体、阶段、权限和期间错一项，结论会变。

## 通用检查

```text
谁
→ 在哪个阶段
→ 作出什么行为
→ 有无权限
→ 是否遵守程序
→ 产生什么效力
→ 如何救济
```

同时判断修法时点、过渡条款和题干行为时间。

## 民事诉讼法

### 管辖

- 受案范围。
- 级别管辖。
- 一般地域与特殊地域。
- 协议管辖、专属管辖。
- 管辖权异议。

### 当事人

- 诉的利益。
- 原告、被告适格。
- 共同诉讼、第三人、代表人、公益诉讼。
- 诉讼承继和当事人变更。

### 证据

- 举证责任。
- 自认、推定、证明妨碍。
- 证据种类和能力。
- 逾期举证和质证。

### 保全、审理和救济

- 保全与先予执行。
- 起诉、受理、送达、答辩、调解、判决。
- 简易与普通程序。
- 一审、二审、再审、执行。
- 上诉、申请再审和执行期限必须查现行法。

### 仲裁

先查仲裁协议是否存在、有效、范围和主体。撤销仲裁裁决与不予执行是不同程序。

## 刑事诉讼法

### 阶段

```text
立案
→ 侦查/调查
→ 审查起诉
→ 审判
→ 执行
```

### 强制措施

拘传、取保候审、监视居住、拘留、逮捕分别判断：

- 对象和条件。
- 决定/执行机关。
- 期限。
- 变更和救济。

### 辩护与证据

- 辩护人范围、介入时间和权利。
- 法律援助、值班律师。
- 口供不能单独定案。
- 非法证据排除。
- 证明责任和证明标准。
- 电子数据、鉴定和勘验检查程序。

### 审判

- 一审、二审、死刑复核、再审、执行。
- 上诉与抗诉。
- 发回重审、改判、维持。
- 认罪认罚、速裁、简易、未成年人等特别程序。

## 行政程序

### 行政行为

先判主体、职权、对象、内容和程序，再判断是否对外产生实际影响。

### 行政复议

- 申请人、被申请人。
- 复议机关。
- 范围和前置。
- 申请期限。
- 决定类型。
- 新行政复议法及过渡规则。

### 行政诉讼

1. 受案范围。
2. 原告资格。
3. 被告。
4. 管辖。
5. 起诉期限。
6. 举证责任。
7. 判决类型。

行政赔偿与刑事赔偿分别处理。

## 证据专题

- 证明对象。
- 证明责任。
- 证明标准。
- 证据能力和证明力。
- 取证合法性。
- 电子数据真实性、完整性和关联性。

## 输出质量

- 先写程序阶段。
- 区分“应当/可以/不得”。
- 不做跨程序救济替代。
- 精确期限必须有现行法依据。
