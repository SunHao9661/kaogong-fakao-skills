# 示例

## 2026 客观题合格线

用户：

```text
2026 法考客观题多少分过？
```

回答：

```text
2026 年客观题全国统一合格线是 180 分。
放宽地区当年为三档：西藏 140 分；指定地区和国家乡村振兴重点帮扶县 150 分；
其他放宽地区 160 分。
这组成绩在 2026 和下一个考试年度有效。
它只是 2026 年度标准，不能自动写成以后每年都是这些数字。
```

## 2026 主观题线不能预设

用户：

```text
2026 主观题 108 分能过吗？
```

回答：

```text
不能先认定。108 分是 2025 年主观题全国统一合格线，
不能自动套到 2026。
2026 主观题合格线应以司法部后续公告为准。
如果你的问题是 2025 年成绩，108 分达到当年全国线；
如果是 2026 年，在公告前只能按“待核验”处理。
```

## 旧法事实

用户：

```text
题干行为发生在 2019 年，可以按现在民法典答吗？
```

回答：

```text
不能直接按现在法覆盖。先确定行为发生时点和当时的法律，
再查新旧法衔接和过渡规则。
如果题目问的是当时效力，应先按当时法判断；
如果另外问今天如何处理，再单列现行法结论。
```

## 官方不公布试题

用户：

```text
这是 2026 法考官方原卷和标准答案吗？
```

回答：

```text
2026 考试公告明确不公布试题及参考答案，所以不能仅凭文件名叫“原卷”
就认定为官方材料。
需要看来历、年份、科目、考生回忆记录和答案来源。
机构整理只能标第三方或回忆版，不能称官方标准答案。
```

## 主观题答案

用户：

```text
甲将房屋卖给乙并交付但未登记，后又给丙登记。乙能否取得所有权？
```

回答：

```text
结论：乙通常不能仅凭交付取得不动产所有权，应分别判断乙的合同请求和丙是否善意取得。

争点：不动产登记、无权处分、善意取得。

规则：不动产物权变动通常以登记为要件；善意取得还要满足无权处分、受让人善意、
合理价格和法定公示等条件。

适用：第一次交易是否完成登记，决定甲再次处分时是否构成无权处分；
丙是否善意、是否支付合理价格、是否完成登记，决定丙的取得。

回答还要回到题目各问，不把“先买先得”当统一结论。
```

## 多选题批改

用户：

```text
我只写了 A 正确，能不能算完整解析？
```

回答：

```text
多选和不定项不能只解释正确项。
至少还要逐项说明 B、C、D 为何符合或不符合构成要件、程序条件或法源。
如果你只写“B 错”，也不够；要写出错在主体、范围、条件还是后果。
```
