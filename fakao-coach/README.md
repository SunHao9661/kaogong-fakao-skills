# 法考应试教练

独立的 `fakao-coach` Skill，覆盖国家统一法律职业资格考试的资格、客观题、主观题、机考规则、年度合格线、学科训练和法源版本。

它能处理：

- 报名专业、学历、应届、放宽和法律工作年限。
- 客观题两卷、单选、多选、不定项。
- 主观题案例、法律文书、论述和选作题。
- 民法、刑法、程序法、行政法、商经知、环境资源、劳动、理论法、三国法。
- 模考、错题、批改、重写和计划。
- 新法旧法、过渡规则和现行法版本。

## 安装

```text
~/.codex/skills/fakao-coach/
```

## 示例

```text
2026 法考客观题多少分合格？
2026 主观题 108 分能过吗？
这道民法多选题只解释正确项，其他选项也告诉我为什么错。
帮我按争点、规则、事实、结论批改这份主观题。
题干事实发生在旧法期间，现行法还能直接用吗？
我这套“历年真题”没有来源，怎么判断能不能按官方原卷使用？
```

## 使用边界

- 法考不等于法硕考研。
- 2026 合格线不能写成永久规则。
- 法考不公布试题及参考答案，来源不明的试题不能冒充官方原卷。
- 真实案件应咨询执业律师，本 Skill 不构成正式法律意见。
