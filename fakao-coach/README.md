# 法考应试教练

面向国家统一法律职业资格考试的 Agent Skill，用同一套流程处理客观题、主观题、案例、批改、模拟卷和备考计划。

## 能做什么

- 客观题：快速判断选项、列出争点、说明法源和易错点。
- 主观题：拆分法律关系、诉讼请求、程序阶段和可争议结论。
- 批改：找出得分点、漏点、规则错误和表达问题。
- 模块训练：民法、刑法、民诉、刑诉、行政法、商经知、理论法、三国法。
- 模考：生成自编客观题或主观题，答案和解析分开。
- 规划：根据基础、剩余时间和目标安排背诵、刷题、案例和模考。
- 来源核验：把法律、司法解释、指导案例和学理观点分开。

## 安装

把整个 `fakao-coach` 目录放入目标 Agent 的 Skills 目录，例如：

```text
~/.codex/skills/fakao-coach/
```

之后直接用法考语言提问。

## 示例

```text
这道多选题选什么，请逐个选项说明，并指出最强干扰项。
按主观题格式分析这个案例，先列争点再给结论。
批改这份主观题答案，按得分点给分，并给一版更规范的示范。
民法合同效力总是错，做一张识别框架和 6 道自编变式。
根据我的剩余 70 天、每天 4 小时，排一份客观题和主观题兼顾的计划。
按当年大纲出一套自编混合模拟题，标明不是官方真题。
```

## 使用边界

考试范围、法条序号、程序期限和评分标准以当年官方文件与现行有效法源为准。技能不会用记忆冒充条号，也不会把自编案例标成官方真题。
