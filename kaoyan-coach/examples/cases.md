# 示例

## 只说“英语三”时

用户：

```text
考研英语三怎么复习？
```

回答：

```text
全国统考外语没有“英语三”。考研常见的是英语一（201）和英语二（204），
另有俄语、日语等。先看目标院校专业目录，确认你实际考英语一还是英语二。
如果目录还没确定，请告诉我专业和学校，我先帮你建立核验清单；
如果已经确定，我可以直接按对应卷种做计划。
```

## 数学卷种未确认

用户：

```text
我考计算机，数学怎么复习？
```

回答：

```text
先不要把数学一、二、三混成一套。计算机相关专业并不自动等于某一卷，
需要看目标院校、专业方向和科目代码。
请先给我学校、专业、业务课科目名称或代码。
如果你还没定学校，我可以先按“数学一常见组合”做路线假设，
但正式计划必须等招生目录确认后重排。
```

## 已确认科目后的计划

用户：

```text
2027 考研，英语二、数学三、政治，每天 3 小时，剩 12 周。
```

回答：

```text
先按三科建立 12 周主线：
1. 基线：各做一次与真实卷种一致的诊断，记录知识、方法和时间问题。
2. 主建设：英语每天词汇/长难句加交替阅读翻译；数学每天计算和一章/一类题；
   政治用选择题反馈，不只看课。
3. 整合：第 7 周起加入混合限时。
4. 冲刺：第 10 周起整卷为主，错题复测，不新增大量资料。

每周至少一次 60—90 分钟完整限时；连续两次同类训练无提升时，
改为缩小范围和重做错因相同的题。
```

## 自命题材料不全

用户：

```text
我买了某校专业课“十年真题”，直接按高频章节复习吗？
```

回答：

```text
先不把它认定为官方十年真题。需要核验学校、专业、科目代码、年份、
是否有官方来源、答案来自哪里。若只是机构汇编或回忆版，可以作为练习样本，
但仍要以当年招生目录、自命题大纲和指定参考书为主。
在当前样本和来源确认前，只能称“现有材料中的常见考点”，不能宣布官方命题规律。
```
