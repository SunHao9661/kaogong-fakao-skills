## 先判任务

| 信号 | 主模式 | 首轮交付 |
| --- | --- | --- |
| 完全不知道流程 | 路线判断 | 初试、复试、国家线、院校线、调剂关系 |
| 专业已定、学校未定 | 择校 | 比较维度和筛选方法 |
| 学校专业已定 | 科目档案 | 单元、代码、科目、资料清单 |
| 有题目 | 单题讲解 | 答案、最短路径、易错点 |
| 有成绩单或错题 | 诊断复盘 | 分差、错因、优先级 |
| 有日期和目标 | 计划 | 阶段、周任务、检查点 |
| 问查分后 | 后续路线 | 复试、调剂或重考 |

## 最小报考档案

```text
考试年份：
目标学校/院系/专业/方向：
学术学位/专业学位：
全日制/非全日制：
统考/单独考试/推免：
业务课一：
业务课二：
自命题或统考：
当前基础：
剩余时间：
每周可用时间：
目标分：
```

只有会改变答案的字段才追问。若用户只问概念，不需要先收集完整档案。

## 事实卡

```text
适用考试：
适用年份：
适用学校/专业/科目：
事实：
来源：
发布日期：
稳定性：稳定/年度/学校自定/用户材料
```

典型处理：

- “2027 初试在 2026 年 12 月 19—20 日”是年度快照。
- “英语一是全国统一命题科目”是稳定结构。
- “某专业考英语二”是学校目录事实，不是全国专业常识。
- “用户上传的自命题真题”是用户材料，不等于官方发布。

## 输出格式

### 路线判断

```text
你现在处于：
已经确定：
还不能确定：
下一步只做这三件事：
核验材料：
```

### 单题

```text
结论：
科目与题型：
解题链：
易错点：
同类训练：
```

### 计划

```text
报考档案：
当前假设：
目标与分差：
阶段表：
周任务模板：
检查点：
调整规则：
```

## 材料等级

| 等级 | 材料 | 处理 |
| --- | --- | --- |
| A | 教育部、研招网、招生单位官方公告/大纲/目录 | 可作规则依据，带年份 |
| B | 用户提供且可确认学校、专业、科目、年份的试题 | 可分析，答案来源另核验 |
| C | 第三方真题汇编、回忆版、机构解析 | 只能作训练与趋势参考 |
| D | 根据大纲编写的变式题 | 必须标自编 |
| E | 无来源押题、内部原题承诺 | 不使用 |

## 缺信息时怎么做

- 只影响细节：先做，标清假设。
- 会改变卷种：先问英语一/二、数学一/二/三或科目代码。
- 会改变资格：要求当年招生目录、招生章程或专项计划文件。
- 会改变真题判断：要求学校、专业、科目代码、年份和来源。
- 连题面关键数字都看不清：停止计算，指出缺失。
