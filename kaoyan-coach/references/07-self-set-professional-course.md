# 自命题专业课

## 为什么不能直接回答

自命题由招生单位组织。专业名称相同，学校、院系、方向、年份不同，科目代码、参考书和题型都可能不同。

必须先确认：

```text
学校：
院系：
专业：
方向：
科目名称与代码：
考试年份：
官方大纲：
指定参考书：
试题来源：
```

## 材料核验

### 官方材料

- 招生章程。
- 专业目录。
- 自命题科目大纲或考试说明。
- 官方参考书目。
- 招生单位公开的样卷或说明。

### 用户材料

- 真题原件或照片。
- 回忆版。
- 学长学姐笔记。
- 课程讲义和题库。

用户材料先判断来源和完整性，再使用。

## 没有大纲时

可以从以下材料反推训练结构，但只能称为“基于现有材料的训练假设”：

- 官方目录中的科目名称。
- 本科同名课程大纲。
- 指定参考书目录。
- 多年度用户真题的稳定题型。
- 招生单位公开说明。

不能宣布“一定考哪些章节”“一定从某书出多少分”。

## 真题分析

每套题记录：

```text
年份
科目代码
题型
每题考点
参考书映射
能力要求
重复模式
缺失信息
```

“高频”至少要有多年、同科目、来源可确认的样本。样本不足时只写“当前材料中的常见点”。

## 学习计划

1. 整理目录和参考书版本。
2. 建立章节框架。
3. 用真题确定题型和表达。
4. 专项训练最容易丢分的题型。
5. 限时整卷与重写。

## 资料选择

优先顺序：

1. 招生单位官方材料。
2. 指定参考书。
3. 用户可确认来源的真题。
4. 与目标科目高度相关的本科课程材料。
5. 来源明确的第三方整理。

不因资料数量多而一起堆入计划。

## 质量检查

- 学校、专业、科目、年份没有丢。
- 没有把别的学校同专业材料混用。
- 没有把回忆版称官方原卷。
- 没有在没有样本时编“命题规律”。
- 计划明确“官方材料缺口”和补证动作。
