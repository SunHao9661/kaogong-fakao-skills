# 模考、错题与考场策略

## 模考先锁结构

组卷前确认：

- 年份与卷种。
- 四单元、三单元或两单元。
- 科目代码。
- 全国统考或自命题。
- 题量、分值和限时。
- 官方真题、真题变式或自编模拟。

结构不明时只能做训练卷，不能称“全真模考”。

## 答题顺序

依次检查：

- 必须先拿的稳定分。
- 高收益但需要时间的模块。
- 容易触发超时的题型。
- 最后检查和平移时间。

不要固定套用他人的顺序。用两次以上模考数据决定。

## 错因分类

| 错因 | 修复 |
| --- | --- |
| 知识不会 | 最小知识卡 + 同类题 |
| 识别失败 | 题型信号训练 |
| 方法不会 | 固定步骤 + 示范 |
| 计算错误 | 计算限时 + 跳步检查 |
| 阅读错误 | 圈限定词、复述题意 |
| 表达失分 | 步骤、结构、术语重写 |
| 时间不足 | 跳题阈值和分块限时 |
| 状态波动 | 作息、顺序、压力管理 |

## 错题卡

```text
科目与卷种：
题目来源：
题型：
我的答案/做法：
正确答案/目标动作：
错因：
必须保留的步骤：
24 小时复测：
7 天复测：
```

## 分数统计

- 总分。
- 单科分。
- 模块得分率。
- 会做但错。
- 不会但猜对。
- 每题平均时间。
- 超时题数量。

不只看总分。

## 真题二刷

- 一刷：限时模拟，保留真实错误。
- 二刷：按题型和错因重做，不背选项。
- 三刷：只看仍不稳定的步骤和识别信号。

## 冲刺策略

- 减少新资料。
- 保持完整套卷。
- 保住已经稳定的分。
- 每次复盘只改一到两个动作。
