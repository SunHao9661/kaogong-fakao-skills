# 管理类综合与经济类综合

## 199 管理类综合能力

常见适用：工商管理、公共管理、会计、旅游管理、图书情报、工程管理、审计等管理类专硕。具体专业入口以当年招生目录为准。

当前稳定结构：

- 数学基础 75 分。
- 逻辑推理 60 分。
- 写作 65 分。
- 满分 200 分。
- 初试与外语组成两单元。
- 思想政治理论通常在复试考核。

### 数学基础

重点不是高数体系，而是算术、代数、几何、数据分析等基础能力。先练准确率和最短路径，再练限时。

### 逻辑推理

- 形式逻辑：命题、推理规则、真假。
- 论证逻辑：加强、削弱、假设、解释。
- 分析推理：排列、分组、匹配、条件约束。

先写条件，再做排除，不凭语感。

### 写作

通常包含论证有效性分析和论说文一类任务。先确认当年题型名称与要求。

论证有效性分析：

```text
找核心结论
→ 拆前提和推理桥
→ 指出具体逻辑问题
→ 解释问题如何影响结论
→ 控制篇幅
```

论说文：

```text
准确立意
→ 明确观点
→ 分层论证
→ 例子服务观点
→ 收束到现实行动
```

## 396 经济类综合能力

当前稳定结构：

- 数学 70 分。
- 逻辑 40 分。
- 写作 40 分。
- 满分 150 分。

具体适用范围以目标院校专业目录为准。不能因为同属经济类就自动认定考 396。

### 数学

重基础、计算和题型迁移。按目标年份大纲确认微积分、线性代数、概率等具体范围。

### 逻辑

与 199 有共通方法，但必须在目标卷种中训练时间和题量，不能直接照搬 199 的完整考场预算。

### 写作

按当年官方要求区分论证分析、论述或其他任务。观点、论证、例证和语言都要服务题目。

## 共同训练方法

- 数学：每天小剂量保持计算，周末综合。
- 逻辑：按题型集中训练后混合。
- 写作：先短提纲，再成文，再做压缩和重写。
- 模考：三科连续完成，练切换与体力和注意力。

## 边界

- 199 和 396 不是同一张卷。
- 管理类专硕不等于所有管理相关专业。
- 经济类专硕不等于所有经济相关专业都考 396。
- 具体科目和是否考政治必须查当年目录与招生章程。
