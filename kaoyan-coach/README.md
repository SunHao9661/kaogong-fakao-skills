# 考研应试教练

`kaoyan-coach` 是一个独立的考研 Skill，覆盖报考路线、择校、公共课、统考专业课、自命题专业课、模考、复试和调剂。

它首先区分：

- 学硕/专硕、全日制/非全日制。
- 统考/单独考试/推免。
- 英语一/英语二及其他外语。
- 数学一/数学二/数学三。
- 199、396、333、408 等具体统考科目。
- 目标院校自命题科目。

全国统考没有“英语三”。目标专业到底使用哪个英语、数学或专业课，必须查看目标院校当年招生目录。

## 安装

把整个 `kaoyan-coach` 目录放入目标 Agent 的 Skills 目录，例如：

```text
~/.codex/skills/kaoyan-coach/
```

## 示例

```text
我准备 2027 考研，但目前只确定专业，帮我判断下一步要查什么。
目标院校确认考英语二和数学三，按每天 3 小时做 12 周计划。
这道数学二题给我最短解法，并说明和数学一/三的边界。
我上传了一份自命题回忆版，请先判断材料来源和可用范围。
初试结束后，帮我对比院校线、排名、复试和调剂路线。
```

## 使用边界

- 不宣称拥有所有学校、所有年份的自命题真题。
- 不把第三方回忆版冒充官方试题。
- 不用上一年度规则自动替代当前年度公告。
- 不把考研英语和大学英语四六级混为一体。
